# Football-Career-mode

A browser-based football career mode game built with **HTML, CSS, and JavaScript**.

## Features

- **Player Career Systems**: attribute training, fitness, morale, growth and season stats
- **Manager Career Systems**: club budget/wage management, tactics focus, youth scouting and contract renewals
- **EA FC-style Core Loops**: fixtures, match simulation, objectives, board confidence and transfer market signings
- **Career Persistence**: save/load/reset using browser localStorage

## Run

Open `index.html` in a browser.
